# به‌روزرسانی بخش ددلاین‌ها

این بسته فقط فایل‌هایی را که برای اضافه شدن سیستم ددلاین لازم است جایگزین می‌کند.

فایل‌های داخل بسته:
- index.html — اضافه شدن لینک و کارت ددلاین‌ها
- deadlines.html — صفحه عمومی ددلاین‌ها، مرتب‌سازی بر اساس نزدیک‌ترین موعد، جست‌وجو و فیلتر درس
- admin.html — اضافه شدن تب «افزودن ددلاین» به پنل مدیریت فعلی
- notes.html — فقط ناوبری به صفحه ددلاین‌ها اضافه شده
- schema.sql — جدول deadlines و Storage bucket مربوط به تصاویر

فایل‌های intro.html و chart.html و supabase-config.js و favicon.svg عمداً دست‌نخورده‌اند و باید در ریپازیتوری قبلی باقی بمانند.

مراحل:
1. محتوای schema.sql را در Supabase > SQL Editor اجرا کن.
2. در GitHub فایل‌های این بسته را جایگزین کن.
3. بعد از Deploy، از deadlines.html یا admin.html وارد شو.
4. با همان حساب مدیر قبلی وارد admin.html شو.
5. برای هر ددلاین می‌توانی عنوان، درس، تاریخ شمسی، ساعت، محل تحویل، لینک، توضیحات و عکس سؤال را ثبت کنی.
